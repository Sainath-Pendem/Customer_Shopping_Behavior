# Customer Shopping Behavior Analysis (Python + SQL + Power BI)

## 📌 Project Overview
This project delivers an end-to-end analytics solution to explore consumer shopping patterns, evaluate category performance, and identify subscription growth opportunities. By analyzing key transaction metrics, demographic segments, and product reviews, the business can make data-driven decisions to optimize marketing strategies and increase Customer Lifetime Value (LTV).

---

## 🛠️ Tech Stack & Architecture
* **Python**: Data cleaning, preprocessing, exploratory data analysis (EDA), and handling missing values.
* **SQL**: Data modeling, querying, aggregated analysis, and structured reporting.
* **Power BI**: Interactive visualization, dashboard design, DAX measures, and business insights reporting.

---

## 📊 Key Dashboard Metrics & Findings
* **Customer Base & Revenue**: Analyzed **3.9K customers** with an average purchase value of **$59.76** and an average review rating of **3.75 / 5.0**.
* **Subscription Conversion Opportunity**: Over **73% (2.85K)** of customers are currently non-subscribers, presenting a major target for loyalty and recurring revenue initiatives.
* **Category Dominance**: **Clothing** ($104K revenue) and **Accessories** ($74K revenue) generate over **76%** of total category revenue.
* **Demographic Evenness**: Revenue across age demographics (Young Adult, Adult, Middle-aged, Senior) is balanced across all categories, indicating broad demographic appeal.

---

🚀 Strategic Recommendations
Target Non-Subscribers: Implement post-purchase incentives (e.g., "Save 10% on your next order by subscribing") to convert the 73% non-subscriber base.

Product Bundling: Bundle high-performing Clothing items with Accessories to raise the current average order value above $59.76.

Optimized Targeting: Focus ad campaigns around product features and seasonal trends rather than strict age segmentation, given the broad demographic purchasing power.

💻 How to Run
Python Setup: Run the Jupyter Notebook in python/ to process raw shopping data.

SQL Ingestion: Load cleaned_data.csv into your preferred SQL database and execute analysis_queries.sql.

Power BI Dashboard: Open Customer_Shopping_Behavior.pbix in Power BI Desktop to view or customize the report visual layout.
